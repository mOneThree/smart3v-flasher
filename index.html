Smart 3V board setup

Install Smart 3V on a new board over USB and get its pairing code. After that, updates arrive through Home Assistant.

Look
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

Plug it in

Connect the board to this computer with a USB cable that carries data, not a charge-only cable. Close any other program that is talking to it.

Won't connect? Unplug it, hold the BOOT button, plug it back in, then let go.

Installing erases the board. A board that was already paired loses that pairing and gets a new code.
